Comprehensive AI Curriculum

A rigorous, structured pathway from foundational coding to advanced generative AI agents.

Download Full Syllabus PDF

Master Python fundamentals including variables, control flow, functions, object-oriented programming, and essential data libraries (Pandas and NumPy) required for handling machine learning datasets.

Explore large language models, system prompts, few-shot prompting, temperature parameters, and integrating OpenAI and Anthropic APIs into web applications.

Understand linear regression, decision trees, clustering algorithms, and model evaluation metrics using scikit-learn.

Build convolutional neural networks (CNNs), process image data using OpenCV, and train custom classification models.

Construct autonomous multi-agent workflows, deploy web applications via Streamlit/Vercel, and present capstone projects on Demo Day.
